📱 スマホアプリとして使えます

ホーム画面に追加して、いつでも復習

このサイトをホーム画面に追加すると、スマートフォンアプリとして今日の復習がいつでもできます。一度開いたページは、電波が弱い場所でも読めます。

✓ いまアプリとして開いています

スマホのカメラで読み取り
iPhone / iPadSafari
  1. Safari でこのページを開く（Chrome ではなく Safari）
  2. 画面下の 共有ボタン（四角から矢印が出ているマーク）をタップ
  3. 「ホーム画面に追加」をタップ
  4. 右上の「追加」をタップ → ホーム画面に「CSD講座」のアイコンが出ます
🤖AndroidChrome
  1. Chrome でこのページを開く
  2. 右上の「⋮」メニューをタップ
  3. 「ホーム画面に追加」または「アプリをインストール」をタップ
  4. 「インストール」をタップ → ホーム画面にアイコンが出ます
🪟WindowsChrome / Edge
  1. Chrome または Edge でこのページを開く
  2. アドレスバーの右端にある「インストール」のアイコン（画面にマイナスが付いたマーク）をクリック
  3. 「インストール」をクリック → スタートメニューとデスクトップから、アプリとして開けます
  4. アイコンが出ない場合は、右上の「⋮」→「キャスト、保存、共有」→「ページをアプリとしてインストール」（Edge は「アプリ」→「このサイトをアプリとしてインストール」）
💻MacChrome / Safari
  1. Chrome：アドレスバーの右端にある「インストール」のアイコンをクリック → 「インストール」
  2. Safari：メニューの「ファイル」→「Dock に追加」（macOS Sonoma 以降）
  3. Dock や Launchpad から、アプリとして開けます
