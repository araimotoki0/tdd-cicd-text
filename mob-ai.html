🎯 Cyber-Dojoとは？

👥 概要

Cyber-Dojoは、
チームでTDD練習ができるオンラインプラットフォームです。

主な特徴

  • • 環境構築不要：ブラウザだけで動く
  • • チーム共有：同じコードをリアルタイムで共有
  • • 信号機表示：テスト結果が赤/黄/緑で一目瞭然
  • • 予測機能：テスト結果を予測してから実行できる

🎯 今日やること

Cyber-Dojoを使って、チームでFizzBuzzをTDDで実装します。
モブAI形式で、全員で1つのコードを作り上げましょう！

4

予測機能（predict）を使おう

🔮 予測機能とは？

テスト結果を予測してから実行する機能です。
自分がコードの状態を把握できているか確認できます。

📝 使い方:

1

「predict」にチェックを入れる

2

red / amber / green のボタンが表示される

3

テスト結果がどうなるか予測してボタンをクリック

4

テストが実行され、予測が当たったか表示される

🎯 予測の意味:

redを選ぶ = テストが失敗すると思う

amberを選ぶ = シンタックスエラーになると思う

greenを選ぶ = テストが成功すると思う

📊 結果の見方:

  • • 予測が当たった → コードの状態を把握できている 👍
  • • 予測が外れた → 何か見落としている可能性あり 🤔

📝 FizzBuzzの仕様 （readme.txt 日本語訳）

📄 readme.txt（原文）:

Write a program that prints the numbers from 1 to 100. But for multiples of three print "Fizz" instead of the number and for the multiples of five print "Buzz". For numbers which are multiples of both three and five print "FizzBuzz".

🇯🇵 日本語訳:

1から100までの数字を出力するプログラムを書いてください。
ただし：

  • • 3の倍数のときは、数字の代わりに「Fizz」を出力
  • • 5の倍数のときは、数字の代わりに「Buzz」を出力
  • • 3と5の両方の倍数のときは「FizzBuzz」を出力

Sample output:

12Fizz4Buzz Fizz78FizzBuzz 11Fizz1314FizzBuzz 1617Fizz19Buzz

... etc up to 100

🎓 発展：1から100まで出力する部分もテストしよう

🤔 ちょっと待って！

仕様は「1から100まで出力する」でしたよね？
今のテストでは fizzbuzz(1), fizzbuzz(3), fizzbuzz(5), fizzbuzz(15) しかテストしていません。
1から100まで正しく出力されるかはテストできていない！

❌ 現状のコードの問題

// これは直接echoしているのでテストしにくい
for ($i = 1; $i <= 100; $i++) {
    echo fizzbuzz($i) . "\n";
}

→ echo は標準出力に出すだけ。PHPUnitで戻り値をテストできない！

✅ テスト可能な設計に変更

Hiker.php - 出力を配列で返す関数を追加

<?php

function fizzbuzz($n)
{
    if ($n % 15 === 0) {
        return "FizzBuzz";
    }
    if ($n % 3 === 0) {
        return "Fizz";
    }
    if ($n % 5 === 0) {
        return "Buzz";
    }
    return (string)$n;
}

// 1からNまでの結果を配列で返す（テスト可能！）
function fizzbuzzAll($end)
{
    $result = [];
    for ($i = 1; $i <= $end; $i++) {
        $result[] = fizzbuzz($i);
    }
    return $result;
}

// 出力
foreach (fizzbuzzAll(100) as $line) {
    echo $line . "\n";
}
?>

※ファイル全体をこれに置き換えてください

<?php
require_once 'Hiker.php';
use PHPUnit\Framework\TestCase;

class HikerTest extends TestCase
{
    public function testReturns1When1()
    {
        $this->assertEquals("1", fizzbuzz(1));
    }

    public function testReturns2When2()
    {
        $this->assertEquals("2", fizzbuzz(2));
    }

    public function testReturnsFizzWhen3()
    {
        $this->assertEquals("Fizz", fizzbuzz(3));
    }

    public function testReturnsBuzzWhen5()
    {
        $this->assertEquals("Buzz", fizzbuzz(5));
    }

    public function testReturnsFizzBuzzWhen15()
    {
        $this->assertEquals("FizzBuzz", fizzbuzz(15));
    }

    // --- 発展：1から100までのテスト ---

    public function testFizzbuzzAllReturnsCorrectSequence()
    {
        $expected = [
            "1", "2", "Fizz", "4", "Buzz",
            "Fizz", "7", "8", "Fizz", "Buzz",
            "11", "Fizz", "13", "14", "FizzBuzz"
        ];
        $this->assertEquals($expected, fizzbuzzAll(15));
    }

    public function testFizzbuzzAllReturns100Elements()
    {
        $result = fizzbuzzAll(100);
        $this->assertCount(100, $result);
    }

    public function testThe100thElementIsBuzz()
    {
        $result = fizzbuzzAll(100);
        $this->assertEquals("Buzz", $result[99]);
    }
}
?>
